# Console Text RPG & Modular CLI

Проєкт реалізує консольний командний інтерфейс для текстової гри із використанням об'єктно-орієнтованих патернів проєктування: Facade, Strategy, Command, Memento та інверсії залежностей для рендерингу.

## Структура проєкту
* `cli/` — фасад `CLI`, парсер аргументів `ArgParser`, стратегії команд та рендерери.
* `core/` — бізнес-логіка гри, персонажі та знімки стану.
* `data/` — збереження та завантаження стану гри у JSON.
* `tests/` — модульні тести командного інтерфейсу.
* `design_doc.md` — дизайн-документ проєкту.

## Запуск
```bash
python main.py
```

## Запуск тестів
```bash
python -m unittest discover tests
```
